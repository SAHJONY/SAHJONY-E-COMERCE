# SAHJONY Sourcing Activation Plan

Status: pipeline-ready; commercial activation gated.

## Current primary programs

- Perfumes Plus Wholesale: official distributor of ARMAF and Sterling Parfums across the Americas; request wholesale catalog, exact SKUs, price sheet, inventory feed, image license, terms, and returns policy. https://perfumespluswholesale.com/
- Ready Distribution: authorized-retailer program requiring business license, resale certificate, MAP agreement, and a $2,500 opening order. Request exact brand eligibility, SKU list, size runs, inventory, image rights, and DTC authorization. https://readydistribution.com/wholesale/
- Shinola Wholesale: direct authorized-retailer request. Request written approval, wholesale catalog, MSRP/MAP, territory/channel terms, imagery rights, warranty handling, and returns constraints. https://www.shinola.com/pages/wholesale-request

## Activation sequence

1. Seed the private 25-candidate intake from Owner OS → Sourcing.
2. Submit retailer applications using verified SAHJONY legal/business details.
3. Store account approval or qualifying invoice evidence outside the public repository.
4. Replace candidate placeholders with exact manufacturer SKUs and permitted product names.
5. Record approved retail price, current inventory, image rights, and fulfillment/returns terms.
6. Promote only fully supported records through the owner catalog API.
7. Enable live sales only after readiness reports verified sellable inventory and all platform gates pass.

No candidate seeded by this plan is public or sellable. Seeding creates private HOLD records only.
